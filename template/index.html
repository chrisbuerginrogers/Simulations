Activation functions

ELU — Exponential Linear Unit (default)

A positive input passes straight through unchanged. A negative input gets squashed toward -1 instead of being cut off at zero, which keeps a small but non-zero slope everywhere -- so the network can keep learning from that unit even when its input goes negative, instead of it getting permanently "stuck." 

f(x) =      x            if x > 0
       α·(eˣ − 1)   if x ≤ 0      (α = 1.0, a fixed constant)

ReLU — Rectified Linear Unit

The simplest and most common option in neural networks generally: anything negative becomes exactly zero; anything positive passes through unchanged. Very cheap to compute, but a unit whose input always ends up negative can get permanently "dead" -- stuck outputting zero forever -- which is exactly the problem ELU (above) is designed to avoid. 

f(x) = max(0, x)

tanh — hyperbolic tangent

Squashes any input into a range between -1 and 1, following a smooth S-shaped curve. An older, classic choice; less commonly used in modern reinforcement learning because it can slow down learning when inputs are very large or very small (a problem called "vanishing gradients"). 

f(x) = (eˣ − e⁻ˣ) / (eˣ + e⁻ˣ)

SELU — Scaled Exponential Linear Unit

The same basic shape as ELU, but multiplied by a specific fixed constant (λ) chosen so that, under the right conditions, the signal passing through many stacked layers automatically settles into a stable, consistent scale on its own ("self-normalizing"), without needing a separate normalization step. 

f(x) =      λ·x               if x > 0
       λ·α·(eˣ − 1)     if x ≤ 0
   (λ ≈ 1.0507, α ≈ 1.6733 -- fixed constants, not tunable)
