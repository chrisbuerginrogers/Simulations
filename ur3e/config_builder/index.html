Standalone task files

The zip bundles both files below plus a README.md walking through everything, including how to get the UR3e robot model and mjlab/mujoco set up in the first place if you don't already have this repo cloned. These files register a standalone Mjlab-UR3e-Reach-Custom task with everything currently selected, so you don't have to hand-edit ur3e_reach_env_cfg.py or __init__.py -- or download them individually below.

train_custom.sh

Save anywhere convenient and run with bash train_custom.sh — first edit the cd line to point at wherever you've placed my_mjlab_project on your own machine (it's a separate project outside this git repo, so the script has no way to guess its location).

custom_ur3e_task.py

Save next to ur3e_reach_env_cfg.py -- either my_mjlab_project/src/my_mjlab_project/tasks/ur3e_reach/ (for real training) or Simulations/ur3e/ (to test in the notebook). Then register it on import: add from . import custom_ur3e_task # noqa: F401 to that package's __init__.py, or just import custom_ur3e_task in a notebook/script.

Activation functions

ELU — Exponential Linear Unit (this project's default)

A positive input passes straight through unchanged. A negative input gets squashed toward -1 instead of being cut off at zero, which keeps a small but non-zero slope everywhere — so the network can keep learning from that unit even when its input goes negative, instead of it getting permanently "stuck." 

f(x) =      x            if x > 0
       α·(eˣ − 1)   if x ≤ 0      (α = 1.0, a fixed constant)

ReLU — Rectified Linear Unit

The simplest and most common option in neural networks generally: anything negative becomes exactly zero; anything positive passes through unchanged. Very cheap to compute, but a unit whose input always ends up negative can get permanently "dead" — stuck outputting zero forever, with no way to recover — which is exactly the problem ELU (above) is designed to avoid. 

f(x) = max(0, x)

tanh — hyperbolic tangent

Squashes any input into a range between -1 and 1, following a smooth S-shaped curve. An older, classic choice from before ELU/ReLU became popular; less commonly used in modern reinforcement learning because it can slow down learning when inputs are very large or very small (a problem called "vanishing gradients" — the learning signal shrinks to almost nothing). 

f(x) = (eˣ − e⁻ˣ) / (eˣ + e⁻ˣ)

SELU — Scaled Exponential Linear Unit

The same basic shape as ELU, but multiplied by a specific fixed constant (λ) that's mathematically chosen so that, under the right conditions, the signal passing through many stacked layers automatically settles into a stable, consistent scale on its own ("self-normalizing"), without needing a separate normalization step like obs_normalization elsewhere in this tool. 

f(x) =      λ·x               if x > 0
       λ·α·(eˣ − 1)     if x ≤ 0
   (λ ≈ 1.0507, α ≈ 1.6733 -- fixed constants, not tunable)
