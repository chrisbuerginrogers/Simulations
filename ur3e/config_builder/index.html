Standalone task files

These two files register a standalone Mjlab-UR3e-Reach-Custom task with everything currently selected, so you don't have to hand-edit ur3e_reach_env_cfg.py or __init__.py. Download them and follow the placement notes below each one.

custom_ur3e_task.py

Save next to ur3e_reach_env_cfg.py -- either my_mjlab_project/src/my_mjlab_project/tasks/ur3e_reach/ (for real training) or Simulations/ur3e/ (to test in the notebook). Then register it on import: add from . import custom_ur3e_task # noqa: F401 to that package's __init__.py, or just import custom_ur3e_task in a notebook/script.

train_custom.sh

Save anywhere convenient and run with bash train_custom.sh. Edit the cd line first if my_mjlab_project isn't at the path assumed below.
